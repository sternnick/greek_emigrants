# Ταξινόμηση Πηγών

[🇬🇧 English](source-classification.md)

| Φάκελος | Ταξινόμηση | Παραδείγματα |
|---|---|---|
| `sources/confirmed/` | confirmed | Εθνικές απογραφές, Destatis, ONS, ABS, StatCan, US Census, Eurostat, UN, OECD |
| `sources/hypothetical/` | hypothetical | Ομοσπονδίες κοινοτήτων, ΜΜΕ διασποράς, ακαδημαϊκές προεκτάσεις |

## Πεδίο reliability

- `high` — επίσημες στατιστικές με δημοσιευμένη μεθοδολογία
- `medium` — ομοσπονδίες κοινοτήτων, γνωστές ΜΚΟ
- `low` — ΜΜΕ, ανεπίσημες εκτιμήσεις, μεμονωμένες πηγές
