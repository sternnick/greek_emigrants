# Source Classification

[🇬🇷 Ελληνικά](source-classification.el.md)

| Folder | Classification | Examples |
|---|---|---|
| `sources/confirmed/` | confirmed | National censuses, Destatis, ONS, ABS, StatCan, US Census, Eurostat, UN, OECD |
| `sources/hypothetical/` | hypothetical | Community federations, diaspora media, academic extrapolations |

## Reliability field

- `high` — official statistics with published methodology
- `medium` — community federations, well-known NGOs
- `low` — media, informal estimates, single-source claims
